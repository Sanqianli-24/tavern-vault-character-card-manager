酒馆角色卡库 0.7.0（Windows x64）
=====================================

从 0.7.0 起提供两种发行包：

  完整安装版（推荐，内置酒馆）：
  release\TavernCardLibrary-Setup-<版本>-x64.exe
  —— 自带完整的 SillyTavern 与独立 Node 运行时，无需单独安装酒馆、Git 或 Node。

  精顺便携版（需电脑上已有酒馆）：
  release\TavernCardLibrary-Portable-<版本>-x64.exe
  —— 体积小、免安装；启动时使用外部 SillyTavern 目录（自动探测或手动选择）。

使用方法：

1. 安装并打开“酒馆角色卡库”——内置模式下打开即是酒馆界面：应用会自动启动
   内置酒馆，启动间隙显示进度过渡页；首次使用会先把酒馆文件复制到用户数据
   目录（仅此一次，约 340MB），之后每次都是数秒内直接进入。
2. 卡库就在酒馆里：打开右侧角色管理面板，按钮行里的书本图标就是“卡库”。
   点开即可浏览/搜索/筛选你的角色卡库：点“导入并开聊”直接把卡导入酒馆并
   开始聊天；“从酒馆收录”区可把酒馆已有的角色一键收进卡库。
3. 批量整理、书架、评分、备份与设置在“完整卡库管理”窗口：酒馆窗口菜单栏
   “角色卡库 → 完整卡库管理”打开；卡片右键菜单/详情面板可“在酒馆中聊天”，
   多选后可“发送到酒馆”。
4. 外部酒馆模式（精简便携版默认）：打开后进入角色卡管理器，点击右上角橙色
   的“启动酒馆”按钮；可在设置里“为外部酒馆安装卡库联动扩展”，安装后刷新
   酒馆页面即可获得同样的卡库面板。
5. 两种方式可在设置 →“酒馆运行方式”里随时切换，切换不会移动任何数据。
6. 关闭窗口时：第一次会弹窗询问“最小化到托盘”还是“彻底关闭”，可勾选“以后
   都这样，不再询问”；之后双击任务栏托盘图标恢复窗口。想改回来可以在托盘
   右键菜单或“••• → 设置 → 关闭窗口时”里调整（每次询问 / 最小化到托盘 /
   彻底退出）。

内置酒馆说明：

- 内置酒馆数据（角色、聊天记录、扩展等）保存在 Windows 用户应用数据目录，
  与外部安装互不影响；升级应用时会保留这些数据。
- 内置酒馆只监听本机（127.0.0.1），不会自动打开浏览器，随本应用退出而关闭。
- 内置 SillyTavern 与独立 Node 运行时均为开源软件（AGPL-3.0 / MIT），
  完整源码随安装包提供，详见 THIRD-PARTY-NOTICES.md。

安全说明：

- 外部模式下软件只读取酒馆目录下的 config.yaml，并调用已有的 Start.bat，
  不复制、不覆盖、不删除 SillyTavern 本体中的任何文件。
- 角色卡管理器自身的卡库数据单独保存在 Windows 用户应用数据目录。
- 0.2.0 新增批量管理：勾选多张角色卡后可批量添加标签、移入书架、评分或删除。
- 0.3.0 更新：标签输入支持逗号或空格分隔一次添加多个；新增评分、格式筛选；
  导入 PNG/JSON 角色卡后自动读取描述、开场白、人设、场景等完整信息；修复拖拽
  导入提示无法关闭的问题；优化筛选与输入时的流畅度。
- 0.4.0 更新：修复旧版导入的卡片详情空白问题。点击任意卡片会自动从本机保存的
  卡文件中补读描述、开场白、人设、场景、对话示例等信息；右上角提供“补读全部
  旧卡”按钮，可一次恢复全部旧 PNG 卡的完整信息。
- 当前安装包是本机自行构建版本，没有商业代码签名。Windows 首次运行时可能显示
  SmartScreen 提示，可选择“更多信息”→“仍要运行”。
- 0.5.0 更新：修复“启动酒馆”失败问题。启动器调用已有的 Start.bat；酒馆自身负责
  打开一个浏览器页面，管理器不会再重复打开。
- 0.5.1 更新：新增“更多标签”面板，可从完整标签列表中选择任意标签进行筛选。
- 0.5.2 更新：合并标签入口为“全部标签”，新增标签搜索；首次打开时清理角色卡文件
  自带的标签，只保留管理器中手动添加的标签。
- 0.5.3 更新：启动酒馆时保留并显示 Start.bat 命令窗口。
- 0.5.4 更新：修复 Start.bat 的 pause 输入导致启动器返回码 1 的问题。
- 0.5.5 更新：修复 Windows cmd 对 Start.bat 路径引号的解析问题，避免启动进程立即返回 1。
- 0.5.6 更新：角色描述文本框扩大至少 2 倍，开场白文本框扩大至少 3 倍；点击当前评分星级可取消评分。
- 0.5.7 更新：新增独立收藏功能，启动后默认进入收藏夹；卡片和详情面板均可切换收藏状态。
- 0.6.0 更新：SillyTavern 安装目录可自定义（设置中选择或自动探测，不再固定
  D:\SillyTavern）；卡片可导出为原始 PNG/JSON 文件（卡片右键菜单、详情面板“导出”
  按钮，多选后可批量导出）；支持 V3 规范（ccv3）角色卡；卡库自动备份与一键恢复
  （••• → 备份与恢复，最多保留 5 份）；重复导入自动跳过；安装版支持在线自动更新
  （••• → 设置 → 检查更新）；新增“深邃/清新”双主题切换；Ctrl+K 快速搜索；
  修复卡片日期显示错误、上传失败误报成功、启动日志残留等多个问题。
- 0.7.0 更新：SillyTavern 本体封装进软件。完整安装版自带固定版本的 SillyTavern
  与独立 Node 运行时，第一次点“启动酒馆”时复制到用户目录（仅一次），随后在应用
  内窗口打开；无需再单独安装酒馆、Git 或 Node。原有外部酒馆模式保留，可在设置中
  随时切换，两套数据互不影响。便携版改为精简发行（不含内置酒馆，使用外部目录）。
